저장 방식이 브라우저의 로컬 저장소

                                

                            

                        


                        

                            
개발자 옵션

                            
테스트 값은 현재 페이지에서만 적용되며 실제 API 설정과 저장된 학교 정보를 바꾸지 않습니다.

                            
                            

                                
구름·강수 렌더링 진단

                                
                                
구름 수·유입 위치, 강수 준비 시간, 색상 전환, 작업 스레드 상태와 프레임 처리 시간을 확인합니다. 설정을 닫으면 화면 왼쪽 아래에 표시됩니다. 끄면 데이터 수집도 중지됩니다.

                                
진단 표시가 꺼져 있습니다.

                            

                            
                            

                                
업데이트·강제 적용 시뮬레이션

                                

                                

                                
실제 버전·빌드 비교, 알림, 카운트다운과 적용 준비 흐름을 사용합니다. 시험 중에는 파일 설치·새로고침을 실행하지 않으며 저장된 업데이트 설정도 바꾸지 않습니다.

                                
시뮬레이션 대기 중입니다.

                                

                            

                            

                                
API 원본·실행 로그·성능

                                

                                
기록을 켠 이후 데이터부터 수집합니다. API는 응답당 최대 64KB·최근 20개, 로그는 항목당 최대 16,384자·최근 100개, 긴 작업·긴 프레임은 최근 200개, 성능 표본은 최근 120개를 보관합니다. 표시 갱신은 초당 1회이며 숨긴 화면은 다시 그리지 않습니다.

                                
성능 측정이 꺼져 있습니다.

                                

                                
기록할 항목을 켜면 시간순으로 표시됩니다.

                                
긴 작업은 50ms를 넘는 실행을 기록합니다. 브라우저가 제공한 프레임·스크립트 위치를 표시하며, 직전 입력과 화면 상태는 참고 정보입니다. 긴 작업과 같은 시점의 긴 프레임이 각각 기록될 수 있습니다.

                                

                                

                                
현재 보관 중인 API 원본·로그·긴 작업·성능 표본 전체를 UTF-8 텍스트로 저장합니다. 한도로 생략된 데이터는 파일에 표시됩니다.

                                
개발자 옵션을 활성화한 동안만 사용할 수 있습니다.

                            

                            

                                
방송·교시·급식 알림 미리보기

                                

                                
저장된 방송, 교시 또는 급식 알림을 하단 pill로 미리봅니다.

                            

                            

                                
긴급 재난 문자

                                
                                

                                
대구광역시 수성구 재난 문자를 5분마다 조회합니다.

                            

                            

                                
시계·시간대

                                

                                
날씨 배경의 시간대 계산에도 반영됩니다.

                            

                            

                                
날씨 API 응답

                                

                                
실시간 날씨 카드 응답을 대체합니다.

                            

                            

                                
급식 API 응답

                                
                                
                                
점심과 저녁 응답을 나눠 급식 화면과 심플 급식 위젯에 적용합니다.

                            

                            

                                
학사 일정 API 응답
date, event, 선택 항목 endDate와 dday를 사용합니다.

                            

                            

                                
날씨 배경

                                

                                    
                                    
                                    

                                        
                                        
                                    

                                    
API 강수값 사용 시 비·소나기·눈의 시간당 양으로 강도를 계산합니다. 해제하면 강수 세기 %를 사용합니다. 프리셋 선택 후 날씨 배경 적용을 누르세요.

                                

                                

                                    
번개 시뮬레이션

                                    
                                    
                                    
시험 프리셋의 번개 · 강한 비/눈을 적용하고 설정을 닫으면 자동 발생을 확인할 수 있습니다. 1회 재생은 강수량과 관계없이 12가지 모양을 순환하며 보여줍니다.

                                    
자동 발생 기준: 비 7.5 mm/h 이상, 눈 2 cm/h 이상, API 강수값 미사용 시 강수 세기 70% 이상. 기기의 동작 줄이기 설정에서는 재생하지 않습니다.

                                
시뮬레이션 값은 날씨 테마에서 보이며 실제 날씨 설정은 변경하지 않습니다.
