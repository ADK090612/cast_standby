v2.7.1
  • 상단 일정 알림 표시를 기본 켜짐으로 변경
  • 기본 시정을 1~7교시 및 오후 급식 시간으로 설정하고 초기화 시에도 기본값 적용
  • 시정을 이름을 붙여 추가·복제·전환할 수 있도록 개선
  • 저장된 선택이 없을 때 기본 테마와 날씨 화면 디자인을 날씨·심플로 설정
  • 교시 시작·종료 pill과 학년별 급식 안내를 1분 표시, 효과음 없음으로 설정
  • 기존 저장값에 급식 종료가 자정으로 저장된 경우 오후 1시 15분으로 바로잡음
  • 시정 편집 화면에서 급식 시간을 4교시와 5교시 사이에 표시
v2.7.0
  • 시스템·시계 글꼴 목록에 글꼴별 미리보기 적용
  • 설정의 불필요한 설명과 여백을 줄이고 초기화 버튼 이름을 가운데 정렬
  • 설정 탭 아이콘을 선명한 색상 배경과 흰색 도형으로 통일하고 라이트 테마 대비 개선
  • 업데이트 확인 로딩 표시를 공통 애니메이션으로 통일
  • 정보 화면에 설정된 학교 이름 표시
  • 기본 디자인에서 시계 전용 설정과 홈의 시계 편집 아이콘 숨김
  • 시계 레이아웃 미리보기 네 가지를 실제 날짜·시간 배치와 일치하도록 조정
  • 시계 크기 슬라이더를 추가하고 부드러운 둥근 스타일 적용
  • 알림을 상단에서 내려오며 블러와 투명도가 서서히 풀리도록 조정
  • 알림 주체별 원형 아이콘과 우측 닫기 버튼 추가
  • 설정 뒤로 가기·닫기 버튼의 외곽 테두리를 없애고 아이콘 스타일 통일
  • 전체 화면에서 아이콘을 축소 표시로 전환
  • 1·2교시 시간을 기준으로 수업·쉬는 시간을 계산해 이후 교시를 자동 입력하고 급식 시간대를 비움
  • 교시 시작·종료와 급식실 안내 문구 개선
  • 설정 화면을 팝업 대신 전체 화면으로 표시
  • 좁은 화면에서도 상단 일정 알림 이름이 끊겨 보이지 않도록 정렬 개선
v2.6.9
  • 대구광역시 수성구 긴급 재난 문자를 5분 간격으로 조회해 새 메시지를 자동 표시
  • 개발자 옵션에서 가상 재난 문자 송출과 실제 API 즉시 조회 지원
v2.6.8
  • 점심과 저녁이 모두 있는 날 칼로리 정보를 좌우로 나눠 표시
  • 업데이트 알림 로딩 애니메이션을 화면 공용 로더와 동일하게 조정
v2.6.7
  • 업데이트 pill 문구 뒤에 로딩 점 애니메이션 추가
  • 자동 업데이트까지 남은 시간과 진행 막대를 알림 pill에 표시
  • 화면 여백 설정에 맞춰 업데이트 pill 위치와 폭을 화면 영역 안으로 제한
  • 석식이 있는 날 급식 박스를 점심·저녁 두 칸으로 나눠 표시
v2.6.6
  • 정보 탭의 개발자 항목을 다섯 번 눌러 개발자 옵션을 여는 기능 추가
  • 업데이트 알림, 시각·시간대, 날씨·급식·학사 일정 API 응답 시뮬레이션 추가
  • 실제 설정을 바꾸지 않고 날씨 배경 상태를 시험하는 기능 추가
v2.6.5
  • 날씨 배경 연산 루프에서 강수 효과가 없을 때 불필요한 캔버스 정리와 화면 표면 탐색을 생략
  • 구름 애니메이션의 반복 객체 생성과 중복 황혼 계산을 줄여 연산 부담 완화
v2.6.4
  • 각 디자인에서 시계를 사각형으로 이동·크기 조절하고 위치를 저장하는 기능 추가
  • 시계 이동·크기 조절 중 화면 중앙축과 가장자리에 자석 정렬 지원
  • 구름을 이루는 원의 크기를 다양화하고 배치를 촘촘하게 조정
  • 날씨 전환 시 잔디 형상 재생성과 구름 스프라이트 일괄 갱신을 줄여 프레임 부하 완화
  • 시계 전용 숫자 글꼴, 초 표시와 한국식·미국식 날짜 형식 선택 지원
  • 시계 글꼴에 동글동글한 스타일, 캡슐형 스타일, 세로로 길쭉한 스타일 선택지 추가
  • 시계 편집 화면과 설정에서 자동·화이트·파스텔 색상 및 투명도 조절 지원
v2.6.3
  • 자동 업데이트 설정 추가 및 활성화·비활성화 지원
  • 자동 업데이트 사용 시 30분마다 새 버전 확인
  • 업데이트 발견 알림 및 1시간 후 자동 새로고침 적용
  • 다른 테마의 급식 상자에서 내부 스크롤을 없애고 내용에 맞춰 높이 조정
  • 급식 메뉴 글자 굵기를 기본으로 조정하고 총 칼로리 정보 추가
v2.6.2

  • 급식 내용에 맞춰 위젯 높이를 조정해 내부 스크롤 방지
  • 시작 시 자동 전체 화면 전환 설정 제공

개발자 옵션

업데이트 알림

방송·교시·급식 알림 미리보기

시계·시간대

날씨 배경의 시간대 계산에도 반영됩니다.

날씨 API 응답

실시간 날씨 카드 응답을 대체합니다.

급식 API 응답

점심과 저녁 응답을 나눠 급식 화면과 심플 급식 위젯에 적용합니다.

학사 일정 API 응답

date, event, 선택 항목 endDate와 dday를 사용합니다.
